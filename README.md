# Logistic Pro — калькулятор грузоперевозок

Пересобранный калькулятор для расчёта межгородских перевозок и экспедирования на основе тарифной базы проекта.

## Что изменено

- новый интерфейс с двухколоночной компоновкой и адаптивностью;
- расчётный движок вынесен из HTML;
- тарифы вынесены в отдельный data.js;
- стили вынесены в styles.css;
- логика приложения вынесена в app.js;
- результат показывает формулу и детализацию стоимости;
- минимальный тариф отображается явно;
- если дополнительная услуга отсутствует в базе, калькулятор больше не подставляет условную ставку;
- история расчётов сохраняется локально;
- сохранён калькулятор плотности 250 кг/м³;
- интерфейс оптимизирован под desktop и мобильные устройства.

## Структура

- index.html — интерфейс
- styles.css — дизайн и адаптивность
- data.js — тарифная база
- app.js — расчётный движок и история
- vercel.json — конфигурация Vercel

## Тарифная база

В data.js перенесены существующие данные из прежней версии: межгородские маршруты, минимальные суммы, ставки экспедирования по городам, отдалённые районы, обрешётка, авизация, МКАД / пробег за пределы города, ПРР, сверхнормативное время и хранение.

Важно: значения не были придуманы заново. Если в исходной базе по услуге нет тарифа, новая версия не делает скрытую подстановку.

## Запуск

Приложение статическое. Достаточно открыть index.html или разместить репозиторий на Vercel.

## Расчёт перевозки

Вес переводится в расчётный объём по коэффициенту: м³ = кг / 250.

Цена маршрута: max(расчётный объём × ₽/м³, минимальная сумма).

## Расчёт экспедирования

Базовый тариф складывается с выбранными дополнительными услугами. Для каждой услуги используется только соответствующая ставка из тарифной базы.
